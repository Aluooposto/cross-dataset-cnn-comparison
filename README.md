Cross-Dataset Comparative Analysis of CNN Architectures

Research Overview

This repository contains the implementation and experimental evaluation of three convolutional neural network architectures: DenseNet, Inception, and Xception, using the CIFAR-10 and CINIC-10 image datasets.

The research investigates model performance across different datasets to examine the comparative effectiveness and generalisation behaviour of the selected architectures.

Models
- DenseNet
- Inception
- Xception

 Datasets
- CIFAR-10
- CINIC-10

 Research Contributions
- Conducted literature review and comparative analysis of the selected CNN architectures.
- Implemented the three deep learning architectures.
- Designed and conducted cross-dataset experiments.
- Evaluated and compared model performance across the selected datasets.

 Repository Structure

- `notebooks/`: Model implementation and experimental notebooks.
- `src/`: Reusable implementation code.
- `results/`: Experimental results and evaluation plots.
- `requirements.txt`: Python dependencies.

 Execution

The notebooks are designed for execution in Python environments supporting the required deep learning libraries. Dataset setup and execution instructions will be provided in the respective notebooks.
